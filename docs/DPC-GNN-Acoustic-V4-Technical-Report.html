1Core Innovation

Physics is not a loss function. Physics is the forward pass.

The GNN learns only material properties (CT → speed of sound / attenuation / scattering). Wave dynamics are executed deterministically by the Leapfrog integrator. There is no physics_weight — this is not a hyperparameter choice, it is an architectural necessity.

3GNN Material Encoder

3.1 Physics-Prior Structure

The speed of sound is decomposed into a known physical prior and a learned residual:

c(x,y) = ctable(HU(x,y)) + ΔcGNN(x,y)

where ctable is a piecewise-linear lookup from established tissue acoustics:

HU RangeTissuectable (m/s)Formula
< -900Air343Constant
-900 ~ -100Fat/Lung1430–15401430 + 0.1375×(HU+900)
-100 ~ 100Soft tissue1480–16001540 + 0.6×HU
100 ~ 1000Bone1600–33001600 + 1.89×(HU−100)

GNN learns the residual Δc — spatial context effects, sub-resolution microstructure, and patient-specific variations that lookup tables cannot capture.

4Deterministic Leapfrog Propagator

Wave Equation

∂²p/∂t² + 2α(x,y) · ∂p/∂t = c(x,y)² · ∇²p + σ(x,y) · s(t)

Leapfrog Discretization

pn+1 = [2pn − (1 − αΔt/2)pn−1 + Δt²(c²∇²pn + σsn)] / (1 + αΔt/2)

Why No Physics Loss?

Proposition 1 (Physics-weight optimality):
For the DPC-GNN-Acoustic architecture, any nonzero physics weight λ > 0 in the loss LPINN = Ldata + λ · r²phys is redundant, because rphys is identically at numerical precision regardless of θ. The gradient ∇θ(λ · r²phys) ≈ 0 contributes only numerical noise. Therefore, λ = 0 is not a hyperparameter choice but an architectural necessity.
